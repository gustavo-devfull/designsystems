# Alert

Mensagem persistente na própria página (não um popup). Para informar sem interromper, use `info`/`success`; para problemas, `warning`/`error`.

<Canvas of={Stories.Default} />

## Usage

```tsx
<Alert variant="error" title="Pagamento recusado" onDismiss={() => setOpen(false)}>
  Verifique os dados do cartão e tente novamente.
</Alert>
```

## Accessibility

- `error` e `warning` usam `role="alert"` (anunciado imediatamente); `info` e `success` usam `role="status"` (anunciado com educação, sem interromper). Sobrescreva com a prop `role` se necessário.
- Ícones são decorativos; o significado está no texto, não só na cor ou no ícone.
- O botão de dispensar é um `IconButton` com nome acessível configurável (`dismissLabel`) e teclado completo.
- Contraste de texto ≥ 4.5:1 nos dois temas (validado nos tokens).
- Alertas que **já existem** no carregamento da página também são anunciados por `role="alert"`; use-os com moderação.
