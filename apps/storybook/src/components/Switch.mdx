# Switch

Ajuste liga/desliga que **entra em vigor imediatamente**. Se o valor só é aplicado ao enviar um formulário, use `Checkbox`.

<Canvas of={SwitchStories.Default} />

## Usage

```tsx
<Switch label="Notificações" checked={enabled} onChange={(e) => save(e.target.checked)} />
```

## Accessibility

- `<input type="checkbox" role="switch">`: anunciado como "interruptor, ligado/desligado". **Espaço** alterna.
- O estado é transmitido por posição **e** cor; a trilha desligada usa `color.border.input` (≥ 3:1) e o botão contrasta com a trilha nos dois estados.
- A transição usa o token de duração, zerado em `prefers-reduced-motion`.
- O rótulo descreve o que é controlado, não o estado ("Notificações", não "Ligar notificações").

## Do & Don't

- **Do**: efeito imediato e reversível.
- **Don't**: não use para ações destrutivas nem em formulários com botão "Salvar".
