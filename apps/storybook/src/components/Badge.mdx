# Badge

Rótulo curto que descreve um estado ou categoria ("Pago", "Rascunho", "Falhou").

<Canvas of={Stories.Default} />

## Usage

```tsx
<Badge variant="success">Pago</Badge>
```

É informativo, não interativo. Para uma ação, use `Button`.

## Accessibility

- **O texto carrega o significado**; a cor só reforça (WCAG 1.4.1). "Falhou" em vermelho, nunca apenas um ponto vermelho.
- Texto sobre fundo ≥ 4.5:1 em todas as variantes e temas (`feedback.*` sobre `feedback.*.subtle`, validado nos tokens).
- É um `<span>`: não cria região nem é anunciado como status. Se a mudança precisa ser anunciada, use `Alert` ou uma região `aria-live` própria.
