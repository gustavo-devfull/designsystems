# Button

Componente de referência do design system: dispara uma ação. Todo outro componente interativo segue as mesmas convenções (API, tokens, estados, testes).

<Canvas of={ButtonStories.Default} />

## Usage

```tsx
import { Button } from "@sette/ui";

<Button variant="primary" size="md" loading={false}>
  Save changes
</Button>;
```

Use **Button** para ações (salvar, enviar, abrir um diálogo). Para navegar para outra página, use um link. Use uma única `primary` por região da tela.

| Variant     | Quando usar                                       |
| ----------- | ------------------------------------------------- |
| `primary`   | Ação principal da tela ou do diálogo              |
| `secondary` | Ação de apoio com peso visual moderado            |
| `outline`   | Ação alternativa em superfícies densas            |
| `ghost`     | Ação terciária, barras de ferramentas             |
| `danger`    | Ação destrutiva ou irreversível (confirmar antes) |

## API

<Controls of={ButtonStories.Default} />

Aceita todas as props nativas de `<button>` e `ref`. `type` é `"button"` por padrão — um Button dentro de um `<form>` não submete por acidente.

## Accessibility

- Elemento nativo `<button>`: papel, foco e ativação por **Enter** e **Espaço** sem código extra.
- `:focus-visible` mostra um contorno de 2px (`outline-focus-ring`) com contraste ≥ 3:1 nos dois temas (validado nos tokens).
- `disabled` usa o atributo nativo: sai da ordem de tabulação e é anunciado como indisponível.
- `loading` mantém o foco (o usuário não perde a posição) e anuncia `aria-busy="true"`; o nome acessível não muda.
- Texto sobre o fundo da ação ≥ 4.5:1 em todas as variantes e estados (`color.text.on-action`).
- Alvo de toque: alturas de 32/40/48px; use `md` ou `lg` em interfaces de toque.
- Animação do spinner desacelera sob `prefers-reduced-motion`; transições usam tokens zerados nesse modo.
- Botão só com ícone: use `IconButton` (com `aria-label` obrigatório), não `Button` sem texto.

## Do & Don't

<DoDont
  doExample={<Button>Save changes</Button>}
  doText="Rótulos curtos, em forma de verbo, descrevendo o resultado."
  dontExample={<Button>Click here</Button>}
  dontText="Rótulos genéricos que não dizem o que acontece."
/>

<DoDont
  doExample={
    <Button variant="danger" leftIcon={<TrashIcon />}>
      Delete project
    </Button>
  }
  doText="Reserve danger para ações destrutivas e peça confirmação."
  dontExample={<Button variant="danger">Cancel</Button>}
  dontText="Não use danger como cor de destaque para ações comuns."
/>

<DoDont
  doExample={
    <Button variant="primary" loading>
      Saving…
    </Button>
  }
  doText="Use loading para operações assíncronas: o layout não pula."
  dontExample={<Button disabled>Saving…</Button>}
  dontText="Não troque por disabled: o foco é perdido e não há indicação de progresso."
/>
