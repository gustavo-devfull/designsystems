# Checkbox

Seleção independente (liga/desliga) ou parcial (`indeterminate`). Para uma opção entre várias exclusivas, use `RadioGroup`; para um ajuste aplicado na hora, use `Switch`.

<Canvas of={CheckboxStories.Default} />

## Usage

```tsx
<Checkbox label="Aceito os termos" required error={errors.terms} />
<Checkbox label="Todos" checked={all} indeterminate={some && !all} onChange={toggleAll} />
```

Controlado (`checked` + `onChange`) ou não controlado (`defaultChecked`), como um `<input type="checkbox">`.

## Accessibility

- O `<input type="checkbox">` real continua sendo o elemento focável e clicável; os ícones são irmãos decorativos.
- **Espaço** alterna. Clicar no texto do rótulo também alterna (`<label for>`).
- `indeterminate` usa a propriedade DOM (anunciada como "parcialmente marcado"); o próximo clique a resolve, como no nativo.
- Contorno de foco ≥ 3:1; borda ≥ 3:1; marca com `color.text.on-action` sobre `action.primary` ≥ 4.5:1.
- Grupos: envolva em `<fieldset>` com `<legend>`.
